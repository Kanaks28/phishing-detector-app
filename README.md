# 🛡️ Phishing Detection Web App

This is a simple and interactive web application built using **Streamlit** that helps users detect:

- 🔗 **Phishing URLs** using a machine learning model trained on custom dataset
- 📧 **Phishing Email IDs** using smart rule-based logic

---

## 🚀 Features

- ✅ Predicts whether a URL is phishing or safe using a trained Random Forest model
- 📬 Checks if an email ID looks suspicious based on patterns, keywords, and domain type
- 🧠 Clean, beginner-friendly UI built with Streamlit
- 🌐 Easy to deploy on Streamlit Cloud or Render
